#### 地理编码触发机制

当配置了LocationIQ API key时，创建地址后会异步触发地理编码：

```php
private function geocodeAddress(): void
{
    if (config('monica.location_iq_api_key')) {
        GetGPSCoordinate::dispatch([
            'address_id' => $this->address->id,
        ])->onQueue('low');
    }
}
```

**关键要点：**
- 使用队列异步处理 (`onQueue('low')`)，避免阻塞主流程
- 仅在配置了`location_iq_api_key`时才触发
- 只传递`address_id`，任务执行时重新查询地址数据

private function getCoordinates()
{
    $query = $this->buildQuery();

    try {
        $response = Http::get($query)->throw();

        $this->address->latitude = $response->json('0.lat');
        $this->address->longitude = $response->json('0.lon');
        $this->address->save();
    } catch (RequestException $e) {
        Log::error('Error calling location_iq: '.$e->response->json()['error']);
        $this->fail($e);
    }
}
```

private function buildQuery(): string
{
    $query = http_build_query([
        'format' => 'json',
        'key' => config('monica.location_iq_api_key'),
        'q' => MapHelper::getAddressAsString($this->address),
    ]);

    return Str::finish(config('monica.location_iq_url'), '/').'search.php?'.$query;
}
```

3. 解析返回的JSON，提取`lat`和`lon`字段
4. 失败时记录错误日志并标记任务失败

## 5. 地址移除与孤立地址删除逻辑

### RemoveAddressFromContact服务

[RemoveAddressFromContact.php](file:///Users/zhangjing/Desktop/so-coders/0508-und-p/monica/app/Domains/Contact/ManageContactAddresses/Services/RemoveAddressFromContact.php)

#### 执行流程
```php
public function execute(array $data): Address
{
    $this->data = $data;
    $this->validate();
    $this->remove();         // 解除关联并可能删除地址
    $this->createFeedItem(); // 创建feed item

    return $this->address;
}
```

#### 地址移除与孤立地址删除

```php
private function remove(): void
{
    // 第一步：解除联系人与地址的关联
    $this->contact->addresses()->detach($this->address);

    // 第二步：检查是否为孤立地址，如果是则删除
    if ($this->address->contacts()->count() === 0) {
        $this->address->delete();
    }
}
```

**孤立地址删除条件：**
- 地址解除与当前联系人的关联后
- 通过`$this->address->contacts()->count() === 0`检查
- **当没有任何联系人关联该地址时**，删除地址记录

#### Feed Item创建与潜在问题

```php
private function createFeedItem(): void
{
    $this->contact->last_updated_at = Carbon::now();
    $this->contact->save();

    $feedItem = ContactFeedItem::create([
        'author_id' => $this->author->id,
        'contact_id' => $this->contact->id,
        'action' => ContactFeedItem::ACTION_CONTACT_ADDRESS_DESTROYED,
        'description' => MapHelper::getAddressAsString($this->address),
    ]);

    $this->address->feedItem()->save($feedItem);
}
```

### 删除顺序对Feed Item引用的潜在影响

**执行顺序：**
1. `detach()` - 解除关联
2. 检查并删除孤立地址
3. 创建feed item并关联到地址

**潜在问题分析：**

| 场景 | 结果 | 风险 |
|------|------|------|
| **地址不是孤立地址** | ✓ 正常：地址存在，feed item关联成功 | 无风险 |
| **地址是孤立地址** | ✗ 问题：地址已被删除，但feed item仍尝试通过`feedItem()->save()`关联 | **外键约束可能失败** |

**问题根源：**
```php
// 在remove()中可能已删除地址
if ($this->address->contacts()->count() === 0) {
    $this->address->delete();  // 地址从数据库删除
}

// 但createFeedItem()仍尝试关联
$this->address->feedItem()->save($feedItem);  // 地址已不存在！
```

**可能的后果：**
1. 数据库外键约束异常（如果`contact_feed_items.feedable_id`有外键约束）
2. feed item的`feedable_id`指向不存在的地址记录
3. 内存中的`$this->address`对象与数据库状态不一致

## 6. MapHelper地址字符串生成逻辑

### MapHelper类

[MapHelper.php](file:///Users/zhangjing/Desktop/so-coders/0508-und-p/monica/app/Helpers/MapHelper.php)

#### getAddressAsString方法

```php
public static function getAddressAsString(Address $address): ?string
{
    $sentence = '';

    if (! is_null($address->line_1)) {
        $sentence = $address->line_1;
    }

    if (! is_null($address->line_2)) {
        $sentence .= ' '.$address->line_2;
    }

    if (! is_null($address->city)) {
        $sentence .= ' '.$address->city;
    }

    if (! is_null($address->province)) {
        $sentence .= ' '.$address->province;
    }

    if (! is_null($address->postal_code)) {
        $sentence .= ' '.$address->postal_code;
    }

    if (! is_null($address->country)) {
        $sentence .= ' '.$address->country;
    }

    // 去除多余空白字符
    return Str::of($sentence)->replaceMatches('/\s+/', ' ');
}
```

**地址字符串生成规则：**
1. 按顺序拼接：`line_1` → `line_2` → `city` → `province` → `postal_code` → `country`
2. 每个非空字段前加空格
3. 使用正则`/\s+/`将多个连续空格替换为单个空格
4. 返回处理后的字符串（可能为空字符串）

#### getMapLink方法

```php
public static function getMapLink(Address $address, User $user): string
{
    $addressAsString = self::getAddressAsString($address);
    if (! $addressAsString) {
        return '';
    }

    $encodedAddress = urlencode($addressAsString);

    return match ($user->default_map_site) {
        User::MAPS_SITE_GOOGLE_MAPS => "https://www.google.com/maps/place/{$encodedAddress}",
        User::MAPS_SITE_OPEN_STREET_MAPS => "https://www.openstreetmap.org/search?query={$encodedAddress}",
        default => "https://www.google.com/maps/place/{$encodedAddress}",
    };
}
```

**地图链接生成：**
1. 调用`getAddressAsString()`获取地址字符串
2. 使用`urlencode()`编码地址
3. 根据用户偏好选择地图服务（Google Maps或OpenStreetMap）

## 7. ReportAddressIndexViewHelper报表聚合逻辑

### ReportAddressIndexViewHelper类

[ReportAddressIndexViewHelper.php](file:///Users/zhangjing/Desktop/so-coders/0508-und-p/monica/app/Domains/Vault/ManageReports/Web/ViewHelpers/ReportAddressIndexViewHelper.php)

#### data方法

```php
public static function data(Vault $vault): array
{
    // 按城市聚合
    $cities = $vault->addresses()
        ->select('id', 'city')
        ->whereNotNull('city')
        ->withCount('contacts')
        ->distinct('city')
        ->get()
        ->map(fn (Address $address) => [
            'id' => $address->id,
            'name' => Str::ucfirst($address->city),
            'contacts' => $address->contacts_count,
            'url' => [
                'index' => route('vault.reports.addresses.cities.show', [
                    'vault' => $vault->id,
                    'city' => urlencode(mb_convert_encoding($address->city, 'UTF-8')),
                ]),
            ],
        ])
        ->unique('name');

    // 按国家聚合
    $countries = $vault->addresses()
        ->select('id', 'country')
        ->whereNotNull('country')
        ->withCount('contacts')
        ->distinct('country')
        ->get()
        ->map(fn (Address $address) => [
            'id' => $address->id,
            'name' => Str::ucfirst($address->country),
            'contacts' => $address->contacts_count,
            'url' => [
                'index' => route('vault.reports.addresses.countries.show', [
                    'vault' => $vault->id,
                    'country' => urlencode(mb_convert_encoding($address->country, 'UTF-8')),
                ]),
            ],
        ])
        ->unique('name');

    return [
        'cities' => $cities,
        'countries' => $countries,
    ];
}
```

### 城市聚合逻辑

**查询阶段：**
- 从vault的所有地址中查询
- 仅选择`id`和`city`字段
- 排除`city`为null的记录
- 使用`withCount('contacts')`统计每个地址关联的联系人数
- 使用`distinct('city')`去重

**处理阶段：**
1. 映射为数组格式，包含：
   - `id`: 地址ID
   - `name`: 城市名称（首字母大写）
   - `contacts`: 关联的联系人数
   - `url.index`: 城市详情页面路由
2. 使用`unique('name')`进行二次去重（处理大小写不一致问题）

### 国家聚合逻辑

与城市聚合逻辑相同，只是将`city`替换为`country`。

### 聚合要点

1. **双重去重机制：**
   - SQL层：`distinct('city')` / `distinct('country')`
   - 集合层：`unique('name')`（基于首字母大写后的名称）

2. **联系人数统计：**
   - 使用`withCount('contacts')`预加载统计
   - 通过`$address->contacts_count`访问

3. **URL编码处理：**
   - 使用`mb_convert_encoding($address->city, 'UTF-8')`确保编码正确
   - 使用`urlencode()`处理URL参数

## 总结

### 关键发现

1. **地理编码异步化**：创建和更新地址时，通过队列异步调用LocationIQ获取GPS坐标

2. **多对多关联设计**：使用`contact_address`中间表支持：
   - 一个地址关联多个联系人
   - 通过`is_past_address`标记历史地址

3. **孤立地址自动清理**：地址解除所有联系人关联后自动删除

4. **潜在bug**：`RemoveAddressFromContact`中删除地址后仍尝试关联feed item可能导致异常

5. **报表聚合优化**：双重去重机制确保城市/国家统计准确

### 建议改进

1. **修复RemoveAddressFromContact的执行顺序**：先创建feed item，再检查并删除孤立地址

2. **feed item数据冗余**：考虑在feed item中直接存储地址快照而非依赖关联

3. **地理编码失败重试**：为GetGPSCoordinate任务添加失败重试机制
